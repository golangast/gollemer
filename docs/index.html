Overview

The Multi-Orchestrator has been enhanced with semantic understanding using a Mixture of Experts (MoE) model and Named Entity Recognition (NER) tagging. Instead of relying on simple keyword matching, it now understands what you're writing in natural language.

Before vs. After

Before (Keyword-based)

The orchestrator would only recognize specific keywords.

  • "create webserver"
  • "create handler"
  • "create database"

After (Semantic Understanding)

Now you can write naturally, and the orchestrator will understand your intent.

  • "I want to build a webserver with an authentication handler"
  • "Make me a Go server that has JWT support"
  • "Create an API with a database for storing user data"

How It Works

The enhanced orchestrator uses a multi-stage NLP pipeline to understand your natural language commands. For a high-level overview of the system architecture, refer to the README.md.

The NLP pipeline proceeds as follows:

The Learning System

Gollemer features a powerful Learning System that allows it to adapt to your specific coding style. The learningfolder serves as a repository for your custom templates and code snippets.

By scanning this folder, Gollemer "learns" new objects based on filenames. This empowers you to automate repetitive coding tasks—instead of writing the same boilerplate, you just ask Gollemer to create the object.

1. Setup (The Object)

You place a file in learningfolder/, for example navbar.html:

<nav>
  <h1>My App</h1>
</nav>

2. The Outcome

After running learn from learningfolder, you can simply type:

create navbar named TopMenu

Gollemer instantly generates TopMenu.html with your code.

Additional Tools

The project includes a suite of powerful tools for training models and interacting with the system in new ways.

  • Model Training: Easily train the Word2Vec, Mixture of Experts (MoE), and intent classification models.
  • MoE Inference: Run inference directly with the MoE model to test its responses.
  • Interactive LLM Mode: A chat-like interface for performing file system operations and asking questions about your project.

LLM Interactive Mode Commands

Once in interactive mode (`go run . -llm`), you can use the following natural language commands. With the new NLP understanding, you are not limited to strict keywords; you can express your intent naturally:

Command Description Example Prompt
Change Directory Navigates to a specified directory. The `gollemer` remembers the last directory you navigated to. `go to myproject`
`cd src`
`switch to the internal folder`
List Directory Contents Lists files, folders, or both in the current directory or a specified path. `list all files`
`ls`
`show me what's in this folder`
Create Folder Creates a new directory. `create folder mydata`
`make a new directory for logs`
Create File Creates a new empty file. `create file README.md`
`generate a main.go file`
Create Handler Generates a new Go HTTP handler function and registers it in `main.go`. `create handler MyHandler with url /myapi`
`add a login endpoint`
Create Page Generates a new WASM frontend page and registers it. `create page dashboard`
`add a view named settings`
Create Component Creates a reusable WASM UI component. `create component Button`
`new ui component Card`
Create Form Generates an HTML form and handler, optionally from a struct or learning data. `create form from User`
`add a form for contact`
Create Webserver Scaffolds a new Go web server project in `cmd//main.go`. `create webserver MyServer`
`build a new API server`
Create Database Creates a SQLite database file and optionally a table with specified fields. `create database myappdb`
`setup a database for users with name and email`
Create Data Structure Creates a Go struct file and a corresponding table in a SQLite database (`jim.db`). `create data structure User with field Name string and Age int`
`define a Product struct`
Delete Folder Deletes a specified directory. `delete folder temp`
`remove the build directory`
Delete File Deletes a specified file. `delete file old.txt`
`remove the temporary file`
History View the history of commands executed in the current session. `history`
`what have I done so far?`
Revert Revert the last operation or a specific command from history. `revert`
`undo the last change`
Print Working Directory Prints the current working directory. `pwd`
`where am I?`
Tree Displays the directory tree structure. Supports depth limit. `tree`
`tree -d 2`
Grep / Search Searches for text patterns in files within the current directory. `grep "TODO"`
`search for "func main"`
Read File Reads and displays the contents of a file. `cat main.go`
`read config.json`
Run / Start Starts a webserver or executes a file. `run webserver MyServer`
`start main.go`
Stop Stops a running webserver. `stop webserver MyServer`
Verify Checks if a webserver is running and endpoints are accessible. `verify webserver`
`check status`
Learn Ingests templates or objects from a specified directory to the Knowledge Base. `learn from ./templates`
`learn object navbar`
